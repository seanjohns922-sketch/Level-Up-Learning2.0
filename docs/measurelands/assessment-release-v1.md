# Measurelands Assessments v1.0

**Status:** Production
**Live from:** 5 August 2026

All 13 Measurelands Pre-Test and Post-Test routes resolve to independent,
assessment-authored banks. The former lesson-derived banks are retained as a
retired archive and are not selectable through the production resolver.

The 85% pass threshold and the existing assessment engine, persistence, replay,
reporting, placement, progression, rewards and database contracts are unchanged.

Item calibration remains `uncalibrated` until representative classroom response
data is available. Production response metadata supports later item difficulty,
discrimination, distractor and misconception analysis.
