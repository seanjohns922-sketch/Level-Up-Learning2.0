# Starpath Levels 2–6: answer-choice review

Reviewed the five 20-question forms at each level (500 questions in total), focusing on the 275 questions with selectable options. The aim is better evidence of understanding, not unfamiliar vocabulary or trick questions. Construction, plotting and route-entry tasks retain their existing demands.

## Changes

| Level | Improvements |
| --- | --- |
| 2 | Parallel-side identification compares quadrilaterals; property explanations contrast one/two pairs and adjacent/opposite sides. Odd-shape reasons use side-count errors instead of colour. Route alternatives use nearby incorrect destinations. |
| 3 | Object names use related solids (for example a cone, cylinder and pyramid). Face/vertex distractors use nearby counts or other familiar feature counts. Comparison questions contrast faces, vertices and equal faces. |
| 4 | Composite descriptions retain the same familiar pieces but misplace one important part. Recomposition alternatives distinguish diagonal cuts from cuts that do not make two triangles. Route-log alternatives finish nearby. Symmetry questions have four reasoned choices, targeting reflection and half-turn misconceptions. |
| 5 | Net identification includes another pyramid instead of a cylinder. Net explanations target face-adjacency misconceptions. Coordinate distractors include counting grid lines incorrectly. Transformation descriptions distinguish sliding from turning about a fixed centre. |
| 6 | Cross-section identification uses other polygons. The hexagonal section competes with a pentagon, heptagon and octagon. Reconstruction from equal cross-sections compares related prisms and a pyramid with the same base family; a hexagonal prism competes with an octagonal prism, pentagonal prism and hexagonal pyramid. Other revisions target signed movement, order of transformations, corner-angle reasoning and turn/reflection confusion. |

The Level 5–6 four-option requirement is retained. Correct answers remain stable. New words in the older levels have the existing option read-aloud controls. No extra shape-name clues were added to the diagrams.

## Review principles

- Preserve a single defensible answer (or the explicitly requested complete selection).
- Prefer a recognisable mathematical mistake to an unrelated object or colour claim.
- Keep foundational recognition accessible at the younger levels.
- Do not claim a measured increase in difficulty without student response data. These revisions improve distractor plausibility; actual difficulty should be checked through student responses.

## Checks

All five level-specific audits cover 500 questions, including geometry, correct answers, invalid responses and matched-form variation. The Level 6 audit independently checks that exactly one reconstruction candidate matches the section's polygon and constant size. The Level 4 audit checks every symmetry distractor against scoring. Browser review covers selectable options, answer recording, read-aloud controls and desktop/mobile layout.
