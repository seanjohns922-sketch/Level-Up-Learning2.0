# Curriculum Source Of Truth

All curriculum audits, curriculum mappings, lesson plans, weekly quizzes and independent assessment banks must be verified against:

**Australian Curriculum: Mathematics - Curriculum content F-6, Version 9.0 (ACARA)**

The project owner's current canonical review copy is:

`/Users/seanjohns/Downloads/mathematics-curriculum-content-f-6-v9 (4).pdf`

## Required Practice

1. Read the relevant year-level descriptor and elaborations in the PDF before approving curriculum alignment or changing curriculum content.
2. Preserve the exact descriptor code and meaning. A shortened description must not omit an assessable verb, representation, range or condition.
3. Verify actual student interactions, not metadata alone. A lesson labelled `create`, `reason` or `model` must require that action.
4. Confirm lesson, weekly-quiz and assessment-bank evidence separately. Shared descriptor coverage does not permit reused questions or lesson-native scaffolding.
5. Record the PDF-derived evidence and any deliberate realm-ownership decision in the relevant audit or blueprint.

Web pages, memory and prior project summaries may support an audit, but they do not replace this PDF as the project's curriculum source of truth.
