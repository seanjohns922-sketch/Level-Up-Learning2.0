# Level 8 Number — five matched forms

Prepared 16 September 2026 for owner review. 30 questions per form, 150 total. Review at `/demo-review/number-level-8`; student banks remain at approved Level 7.

Source: the supplied Australian Curriculum v9 documents `mathematics-curriculum-content-7-10-v9.docx` and `mathematics-scope-and-sequence-f-10-v9.docx`, Year 8 Number content descriptions. Other Year 8 strands remain separate realms.

| Code | Slots | Focus |
|---|---|---|
| AC9M8N01 | 1–4 | Irrational square roots, bounds and pi |
| AC9M8N02 | 5–10 | Product, quotient, power-of-power and zero-exponent laws; numerical bases |
| AC9M8N03 | 11–14 | Terminating fractions, recurring expansions and repeating digits |
| AC9M8N04 | 15–22 | Integer operations, signed fractions and decimals |
| AC9M8N05 | 23–30 | Markup, GST, successive changes, offers, percentage growth, tiered tax and water modelling |

All forms preserve slot-level skill, response type and intended difficulty, with different examples. Difficulty is judged against end-of-Year-8 expectations: three accessible anchors, twenty moderate items and seven challenging modelling/combined-operation items. This is author judgement, not empirical calibration or psychometric equating. The forms support practical growth tracking; student response data will be needed to establish measured equivalence.

Visuals use Number Nexus colours, square/circle diagrams, exponent notation, fractions, meaningful context artwork and clearly labelled quantities. Calculation questions have no shaded fraction clues. Tax uses an explicitly fictional supplied table, not current tax advice. Read-aloud includes the quantities needed to solve each question. Signed numeric answers allow minus signs.

Verification: independent answer keys for all 150 items, scorer acceptance/rejection, exactly one correct option, distinct rational distractors, terminating/recurring classifications, five different examples in each slot, protected review access, server-render checks and the project build.

Manual review: check the five forms using the top form selector; focus on clarity, visual comfort and the experience of a Year 8 child. No Level 8 student release is included.
