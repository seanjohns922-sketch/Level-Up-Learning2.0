# Statistica Level 8 — five matched review forms

Five forms, 30 questions each. Approved content is now frozen into the student release; see `../releases/statistica-1-8-assessments.md`. Demo Review remains available.

Read the user's `mathematics-curriculum-content-7-10-v9.docx`, Year 8 Statistics section. Unlike Year 7, Year 8 has four Statistics content descriptions:

| Code | Slots | Assessed content |
| --- | --- | --- |
| AC9M8ST01 | 1–7 | Census, sampling practicalities, experiment versus observation, random selection, selection bias and instrument precision |
| AC9M8ST02 | 8–14 | Primary/secondary sources, random/non-random methods, sample distributions and their mode/median/mean, reporting scope and voluntary-response bias |
| AC9M8ST03 | 15–22 | Sample proportions, equal-size random sample variation, population estimates, sample-size effects, removing an extreme and uncertainty |
| AC9M8ST04 | 23–30 | Ethical and fair investigation plans, target population, non-response denominator, digital display construction, bounded reports, uncertain estimates and sampled field plots |

The forms sample investigation planning and analysis; they do not pretend that supplied records are students' own fieldwork. Existing weekly lesson content currently stops at Level 6. Year 8 assessment design follows the document directly, with curriculum groups rather than lesson-week claims.

Reuse the shared graphs, tables, dataset cards and plant setup illustration. New sampling-frame diagrams display 60 individually countable units with selected units highlighted, a one-symbol key and selected/population counts. They illustrate the stated selection method; the spatial pattern alone is not presented as proof of random selection. Exact percentage labels appear where scale interpolation would be ambiguous.

Progression: frequencies up to 500 in a 1,000-observation sample, population estimates for 1,000 people, repeated samples of different sizes, and explicit percentage-point comparisons. Keep smaller raw datasets when testing how an extreme affects the mean. Four options per multiple-choice task; concise later-item wording; all visible evidence narrated by nearby read-aloud controls.

Validation includes 150-item audit, 7/7/8/8 code coverage, matched form demand, distinct distractors, independent calculations, valid/unique highlighted frame units and scoring. Browser verification covers visible sources, graph geometry, all five forms, 30/30 results, mobile overflow, and all five Demo Review entry points plus return navigation.
