# Pattern Peaks Level 8 review

Five parallel forms (Pre-Test, Post-Test, Start, Mid, End), 30 questions each. Review only; no student-result writes or live-bank replacement. Level 8 weekly lessons are not implemented by this change.

Source: owner-supplied `mathematics-curriculum-content-7-10-v9.docx`, Year 8 Algebra table (Australian Curriculum v9).

| Code | Questions | Assessed content |
| --- | --- | --- |
| AC9M8A01 | 1, 2, 6, 11, 16, 21, 23, 26 | Create, expand, factorise, rearrange and simplify linear expressions; distribution, like terms and inverse operations |
| AC9M8A02 | 3, 7, 8, 12, 13, 17, 18, 22, 27, 28 | Equations, substitution checks, inequalities algebraically and graphically, coordinates, plotting and vertical relations |
| AC9M8A03 | 4, 9, 14, 19, 24, 29 | Financial formulas, pay, break-even, whole-item budget limits and model validity |
| AC9M8A04 | 5, 10, 15, 20, 25, 30 | Digital graph investigations of intercept, signed gradients, steepness, horizontal and parallel lines, and intersections |

The digital investigations require students to calculate both specified settings before recording an answer. They display a live graph and retain earlier coordinate results. These questions assess experimenting with functions, not just recalling a rule. The graph lab accepts integer gradients and intercepts from −8 to 8. Independent audits check each required comparison.

Forms vary numeric settings using an interleaved variant schedule and rotate the four choices. Some invariant answers (e.g. the break-even duration) deliberately remain equal while coefficients change. Distractors target distribution, sign, endpoint and context mistakes. Questions progress from one-step simplification to equations with both sides, graph inequalities and model limitations.

Existing lesson CartesianGridVisual and InputOutputTableVisual were inspected. The established Pattern Peaks review graph, plotting and formula-lab components are extended to retain realm styling and read-aloud coverage. Fractions continue to use the shared formatter. Negative response values are enabled explicitly for this level; earlier number-entry rules are preserved.

Validation: 150 independently worked responses, per-code coverage, distinct choices, graph bounds, incomplete-experiment rejection, contextual budget bounds, five demo entry routes, TypeScript/lint/prebuild and browser interaction checks. Browser checks exercise all five scores, mobile overflow, plotting, signed inputs, experiment history, read-aloud controls and skip/back navigation.
