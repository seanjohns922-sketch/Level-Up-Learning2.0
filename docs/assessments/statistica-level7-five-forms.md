# Statistica Level 7 — five matched review forms

Pre-Test, Post-Test, Start, Mid and End contain 30 questions each (150 total). Added to Demo Review only; student-live assessment selection and login permissions are unchanged.

## Curriculum source

Read the user's `mathematics-curriculum-content-7-10-v9.docx`, Year 7 Statistics section. The document specifies three codes:

| Code | Slots | Evidence |
| --- | --- | --- |
| AC9M7ST01 | 1–10 | Discrete and measured datasets; mean, odd/even median, mode, range, frequency-weighted mean; impact of extremes; useful measures of centre; missing values and equal-centre comparisons |
| AC9M7ST02 | 11–20 | Ordered stem-and-leaf interpretation and editable construction, dot-plot construction, skewness, centre and spread comparisons |
| AC9M7ST03 | 21–30 | Numerical investigation question, comparable continuous measurements, anomaly validation, measured median, frequency construction, performance comparison, outlier-aware reporting and scope limits |

Practical acquisition and full real-world investigations are not simulated as completed fieldwork. These forms assess decisions, organisation, digital construction and analysis of supplied records. The existing Statistica weekly activity bank currently ends at Level 6; no Level 7 lesson coverage is claimed. Review labels say curriculum group rather than lesson week.

Inspected existing lesson and review graph/media renderers before authoring. Shared numerical-dot plotting and frequency controls are reused. The new ordered stem-and-leaf component preserves exact values, repeated leaves and an explicit key. Construction uses editable rows, not an already-completed plot. Values are shifted between forms with matched sample size and arithmetic demand.

## Progression and wording

A 1,000-observation frequency table has frequencies up to 400. Raw datasets remain 4–12 observations so mean/median and ordered-stem work test reasoning rather than lengthy transcription. Dot-plot frequencies remain small because each dot represents one observation. Twenty-four to thirty use short scenarios and concise choices rather than long passages.

All multiple-choice questions have four distinct options. Read-aloud covers the prompt, visible source, options and entered stem rows. Numbered navigation supports all 30 questions; answers are recorded through the shared flow without a separate Done button.
