# Statistica Level 5 — five matched review forms

Pre-Test, Post-Test, Start, Mid and End each contain 20 questions. Available through Demo Review; this change does not release a new student assessment bank.

Checked against the supplied Mathematics Curriculum Content F–6 v9 document and the existing Statistica Level 5 weekly activities and line-graph lesson renderer.

| Curriculum code | Slots | Assessed evidence |
| --- | --- | --- |
| AC9M5ST01 | 1–7 | Nominal versus ordinal categories, discrete numerical data, digital recording and validation, mode (including tied modes), distribution shape |
| AC9M5ST02 | 8–14 | Read time-series observations, changes and differences between changes, horizontal segments, steepness, supported conclusions and limits of interpolation/prediction |
| AC9M5ST03 | 15–20 | Investigation questions, collection plans, duplicate validation, constructing a display, comparing results and reporting within scope |

The assessment samples the investigation process; completing a real class investigation remains lesson work. Weekly alignment: types in Week 1, records in Week 2, distributions in Week 3, line graphs in Week 4, inference in Week 5, investigations in Week 6.

Reading frequencies reach 150 and column construction reaches 140 (versus 100/80 in Level 4). Line graphs use observed quantities up to 200, which are not all frequencies. Short record lists assess accurate entry and cleaning without repetitive transcription. Five points, hourly intervals, fixed scales and marked observations remain comparable across forms.

Every multiple-choice item has four distinct options. The shared review flow retains numbered navigation, Back/Next, read-aloud and a separate I don’t know action. Record tables display each participant and response; line graphs expose observed points, labelled axes and consistent scales. No feedback is provided before review details are opened.

Validation: bank audit checks all 100 items, 7/7/6 curriculum distribution, matched demand, answer uniqueness, scoring, record evidence and independent line-change calculations. Browser checks cover all five complete forms, visible record values, plotted point geometry, mobile overflow, navigation and runtime errors.
